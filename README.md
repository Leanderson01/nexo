# Nexo Assist

Agent de atendimento do service desk de TI da Nexo. O README completo chega na task T18
(ver `TASKS.md`).

## Rodar localmente (provisório)

```bash
npm install
cp .env.example .env.local   # e preencha as chaves
npx convex dev               # em um terminal
npm run dev                  # em outro
```
